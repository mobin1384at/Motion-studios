# Particles — 8s — مثال: انیمیشن ذرات «سپاریک»

انیمیشن ۸ ثانیه‌ای عمودی (۱۰۸۰×۱۹۲۰) به سبک `particles`: هزاران ذره‌ی درخشان می‌چرخند،
کلمه‌ی «سپاریک» را می‌سازند، چند ثانیه نگهش می‌دارند و دوباره پراکنده می‌شوند.

- فایل: `particles-8s.html` — تک‌فایل، بدون وابستگی خارجی (به‌جز فونت Lalezar از `assets/fonts/`).
- تایم‌لاین: ۰–۲ ثانیه جمع‌شدن ذرات، ۲–۶ ثانیه نگه‌داشتن با درخشش ملایم، ۶–۸ ثانیه پراکنده‌شدن (لوپ تمیز).
- قرارداد رندر: `seek(t)` هر فریم را تابع خالص زمان می‌سازد (PRNG بذردار، بدون `Math.random`) — همان ورودی، همان ویدیو.

## رندر — ✅ رندر شده و تأیید شده (۲۰۲۶-۱۱-۱۱)

رندر نمونه با `capture.mjs` + Chrome هدلس + ffmpeg روی همین ماشین انجام شد:
`particles-8s.mp4` — ۸ ثانیه، ۱۰۸۰×۱۹۲۰، ۲۴ فریم، h264، QC: PASS (۰ فریم سیاه، ۸ فریم
متمایز). فریم‌ها دیده و تأیید شدند: ذره‌ها کلمه‌ی «سپاریک» را می‌سازند و زیرنویس
«کتاب خوب، دوباره خوانده می‌شود» درست شکل گرفته است. فایل MP4 در همین پوشه است.

```bash
# از ریشه‌ی اسکیل:
cd motion-studio

# کپچر فریم‌به‌فریم + اسمبل به MP4 (۲۴ فریم بر ثانیه، ۸ ثانیه = ۱۹۲ فریم)
# capture.mjs خودش فریم‌ها را می‌گیرد و با ffmpeg به MP4 تبدیل می‌کند.
# اگر /tmp کوچک است، MOTION_STUDIO_TMPDIR را به پوشه‌ای با فضای کافی بدهید.
MOTION_STUDIO_TMPDIR=./.frames-tmp node scripts/capture.mjs \
  --input examples/particles-8s/particles-8s.html \
  --output examples/particles-8s/particles-8s.mp4 \
  --fps 24 --duration 8 --width 1080 --height 1920
```

نکته: `capture.mjs` باید پیش از شروع، `document.fonts.ready` را صبر کند تا فونت Lalezar
کامل لود شود؛ وگرنه نمونه‌برداری از شکل متن با فونت جایگزین انجام می‌شود.
